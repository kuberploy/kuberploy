# Support

Kuberploy is community-supported software under active development.

- Use GitHub Discussions for setup questions, ideas, and general help.
- Use GitHub Issues for reproducible defects and accepted feature work.
- Use the private security-reporting path for vulnerabilities.

Include the Kuberploy version, Kubernetes version, installation mode, relevant
operation ID, redacted logs, and minimal reproduction. Never post bootstrap
tokens, session cookies, GitHub App keys, webhook secrets, registry credentials,
kubeconfigs, or unredacted application secrets.
